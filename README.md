# Длинная арифметика на ассемблере

Реализация длинной арифметики на ассемблере NASM для Linux x86-64. Проект содержит три самостоятельные консольные программы для сложения, вычитания и умножения больших неотрицательных целых чисел.

## Инструментарий

- **NASM** — ассемблер, синтаксис Intel, формат объектных файлов ELF64.
- **GNU ld** — компоновщик для создания исполняемых файлов.
- **Linux x86-64** — целевая платформа. Ввод, вывод и завершение программ выполняются напрямую через системные вызовы `syscall`, без стандартной библиотеки C.

## Что сделано

| Файл | Операция | Реализация |
| --- | --- | --- |
| `src/add.asm` | Сложение двух длинных чисел | Поразрядное сложение 64-битных слов с переносом через `adc`. |
| `src/sub.asm` | Вычитание второго числа из первого | Поразрядное вычитание с заёмом через `sbb`. |
| `src/mul.asm` | Умножение двух длинных чисел | Накопление частичных произведений с использованием циклического буфера на стеке. |

Также реализованы:

- хранение каждого входного числа в массиве из 128 64-битных слов — **8192 бита**; для произведения используются 256 слов — **16384 бита**;
- преобразование десятичного ввода во внутреннее представление через умножение на 10 и прибавление очередной цифры;
- преобразование результата в десятичную строку через последовательное деление на 10 и вывод в стандартный поток;
- вспомогательные процедуры сложения с 64-битным числом, умножения и деления на 64-битное число, обнуления и проверки на ноль;

Сложение и вычитание выполняются по модулю `2^8192`: выход за разрядную сетку не диагностируется, отрицательные результаты в знаковом виде не поддерживаются.
